# Отчёт по людям

React-приложение для ручного внесения отчётов по людям и качеству, хранения данных в SQLite, разграничения доступа по объектам и просмотра истории изменений.

## Возможности

- ручное внесение плана, факта, причин, решений и оценки качества;
- автоматическая проверка обязательных полей и пятничной оценки;
- обновление по ключу `Объект + дата + вид работы + детализация + подрядчик`;
- сохранение истории каждого внесения через интерфейс;
- обратимый откат внесений с восстановлением предыдущих значений;
- роли `Администратор`, `Руководитель проекта`, `Сотрудник Департамента ресурсов`;
- ручные права пользователей на строительные объекты;
- дашборд, фильтры, краткое резюме и экспорт отображаемого отчёта в PNG;
- локальные черновики незавершённой формы.

## Локальный запуск

Требуется Node.js 22.5 или новее: SQLite используется через встроенный модуль `node:sqlite`.

```powershell
Copy-Item .env.example .env
npm.cmd install
npm.cmd run dev
```

Интерфейс: `http://localhost:5173`. API: `http://localhost:3000`.

## Тестовые пользователи

При `AUTH_MODE=dev` автоматически создаются администратор, руководитель проекта и сотрудник Департамента ресурсов. Администратор может переключить тестового пользователя в разделе «Пользователи и права».

## Production

```powershell
npm.cmd install
npm.cmd run build
npm.cmd start
```

После сборки backend раздаёт интерфейс и API на порту 3000. Также доступен запуск `docker compose up -d --build`. Файл SQLite необходимо включить в резервное копирование.

## Bitrix24

Точка расширения находится в `apps/server/src/auth/bitrix.js`. До подключения портала приложение работает только с `AUTH_MODE=dev`. Для production необходимо реализовать проверку контекста запуска Bitrix24 и выдачу внутренней сессии.

## Откат внесений

Каждое сохранение через форму фиксируется в истории. При отмене созданные записи удаляются, а обновлённые восстанавливаются. Если строки уже изменены более новым внесением, сначала необходимо отменить более новое изменение.
